Main interaction: Submit the form above to add a new inventory item. It is placed automatically in FIFO (first-in-first-out) order by expiration date, with its expiration alert and total value calculated for you.

Standing rule: The inventory list always sorts by soonest-to-expire (perishable date) first - FIFO order - and no edit or addition may ever cause older stock to display below newer stock. Adjusting a quantity re-renders the ledger but never changes this ordering; only an item's own expiration date can move it in the list.
